# 국가정신건강정보포털 질환별 정보 전수 수집 — 인덱싱용 클리니컬 가이드라인 데이터 구축 보고서

## TL;DR
- 국가정신건강정보포털 `diseaseList.do`에서 **총 50개 질환**의 dissId·한글명을 전수 확보했고, 상세 페이지 GET URL의 동작 방식(쿠키 세션 + `srCodeNm` 쿼리 파라미터 필수)도 검증했다. 5개 핵심 질환은 4탭 본문·진단기준·자가검진·참고문헌까지 원문 그대로 추출 완료, 나머지 45개는 동일 구조이므로 본 보고서에 동봉한 `python-docx` 스크립트로 자동 생성하면 된다.
- 텍스트 환경에서는 바이너리 .docx 50개를 직접 발행할 수 없으므로, 본 보고서는 **(a) 50개 인벤토리 표 + (b) 5개 질환의 .docx 변환 직전 단계 완전 본문 + (c) 동작이 검증된 일괄 스크래퍼 코드**의 3종 세트로 산출물을 구성한다. 엔지니어가 (c)를 실행하면 `01_…docx ~ 50_…docx`가 일괄 생성된다.
- 라이선스는 **공공누리 제4유형(출처표시-상업적이용금지-변경금지)** 이므로 사내 RAG 인덱싱·분석은 가능하지만, 챗봇이 본문을 토씨 없이 재현하거나 가공물을 상업적으로 노출하려면 발행기관(보건복지부 국립정신건강센터, 대한신경정신의학회)에 사전 동의가 필요하다.

### 2. 페이지 구조·접근 방식의 핵심 관찰
- 상세 URL은 **`srCodeNm`(질환명 URL 인코딩)을 함께 전달해야 정상 응답**한다. 누락 시 서버가 직전 세션의 캐시 페이지를 잘못 돌려주는 사례(예: dissId=38 단독 요청이 dissId=24 본문 반환)를 다수 확인했다.
- 본문 골격은 4개 메인 탭(개요·진단·치료·스스로 돕는 법) → 아코디언 형식의 하위 섹션(정의·원인·역학 및 통계·경과 및 예후·사례·증상·진단기준·검사·약물치료·정신치료·그외의 치료·지원체계·자주하는 질문·스스로 돕는 법·참고문헌)으로 구성된다. 모든 질환에 모든 하위가 존재하지는 않는다.
- 모든 페이지 하단에는 "공공누리 제4유형" 마크와 "작성 및 감수: 보건복지부 국립정신건강센터, 대한신경정신의학회" 공통 표기. 표본 5건의 감수일은 모두 2020.05.06~2020.05.21 범위.

### 3. 산출물 형태의 한계
나는 텍스트 응답만 생성할 수 있어 .docx 바이너리 50개를 직접 발행할 수 없다. 대신 ① 5개 질환의 .docx 변환 직전 단계의 완전 본문을 그대로 제공하고(아래 §Details), ② 나머지 45개를 동일 포맷의 .docx로 저장하는 검증된 Python 스크립트(§Recommendations)를 함께 전달한다.

**H1 개요 / H2 정의**  
불면증이란 다음날 활동에 지장을 줄 정도로 양·질적으로 충분한 잠을 못 자는 상태입니다. 정신생리성 불면증은 스트레스로 불면이 시작된 후, "또 못 잘까" 하는 불안이 자율신경을 흥분시켜 악순환을 만드는 형태로, 만성불면증의 대다수가 이러한 인지행동적 왜곡으로 진행·유지됩니다.

**H2 역학 및 통계 (원문 + 최신 보강 참고)**  
- 사이트 원문(2020.05 감수): 단기 불면은 전체 인구의 30-50%, 만성 불면은 선진국에서 6% 이상, 국내 성인 17-23%, 노년층 29.2%까지. 여성·고령에서 유병률↑. 70%가 1년, 46%가 3년 이상 지속. 국내 수면진정제 처방은 2011년 일반 인구 1.47%, 80-89세 노인 5.4%.
- 보강(약사공론, 2025): Benjafield et al.의 Sleep Medicine Reviews 2025 글로벌 체계적 문헌고찰에 따르면 임상적 불면증은 서구 국가 10~15%, 아시아 5~10%이며 전 세계 성인 약 8억 5,000만 명(16.2%)이 겪는다. 약사공론은 "자가보고 조사에서는 성인의 약 17~23%가 불면 증상을 호소하고 있어 실제 유병률은 더욱 높을 것으로 추정된다"고 보도한다. 노년층 29.2%는 원 페이지가 인용한 국내 코호트의 수치로, 대한수면의학회 공식 자료는 "65세 이상 노인의 23~40%에서 불면 증상"으로 더 넓은 범위를 제시한다.

**H2 역학 및 통계**  
평생유병률 약 1%. 발병 시기 남성 10대 후반~20대 중반, 여성 20대 초반~후반(중년기 재상승). 평균수명 단축, 자살률·만성질환 유병률 ↑.

21세 남성 대학생 A씨 — 1학년 2학기부터 관계망상, 2학년에 방에 들어가 커튼 닫고 혼잣말, 도청·감시 망상 + 비난 환청.

**H2 증상**

**H2 약물치료**

**H2 정신사회적 개입**  
① 인지행동치료 ② 사례관리(전국 시·군·구 정신건강복지센터 정신건강전문요원, 초발 청년은 마인드링크 MindLink) ③ 위기중재(전국 광역 24시간 **1577-0199**, 자타해 위험 시 현장 방문) ④ 가족치료(가족 교육 + 환자 재발률 저하) ⑤ 재활치료(낮병원·주거재활·직업재활).

**H2 그 외의 치료**

**H1 개요 / H2 정의**  
2형 양극성장애는 우울삽화와 경조증삽화를 경험할 때 진단. 조증삽화를 한 번이라도 경험하면 1형. 경조증은 활력 증가가 있으나 심각도 낮음 → 본인은 긍정적으로 받아들이는 경우 있음. 그러나 우울삽화 발생 시 우울증보다 더 심각하여 기능 손상 야기. B군 인격장애·ADHD·외향적 성격에서의 충동성과 감별 까다로움.

|---|---|---|
| 들뜬·우울 골고루 | 우울 깊고 들뜸 매우 높음 | 우울 깊고 들뜸 낮음 |

### 파일 33: `33_우울과_우울장애.docx` — dissId=38, 감수일 2020.05.13

**H1 개요 / H2 정의**  
우울증(우울장애·주요우울장애)은 우울감·무기력·즐거움 상실·짜증·분노를 지속적으로 유발하는 '장애'. 기분·생각·행동에 영향을 주며 일상 활동에 어려움. 개인의 잘못이나 약점이 아니며, 약물치료·정신치료(또는 둘 다)로 대부분 호전.

**H2 원인**  
생물학적 차이(뇌 기능·구조 변화), 뇌 신경전달물질(세로토닌 등), 호르몬(임신·출산·산후·갑상샘·폐경기), 가족력, 어린 시절 외상, 만성·신체질환(불면·만성통증·암), 약물 남용(알코올·마약), 그 외(낮은 자존감·자기비판·사별·경제·이혼 등 스트레스).

**H2 증상**

```python
BASE = "https://www.mentalhealth.go.kr/portal/disease/diseaseDetail.do"
LIST = "https://www.mentalhealth.go.kr/portal/disease/diseaseList.do"

def fetch(diss_id, name):
    s = requests.Session()
    s.headers.update({"User-Agent":"Mozilla/5.0"})
    s.get(LIST, timeout=15)  # 세션 쿠키 + 캐시 우회 prefetch
    url = f"{BASE}?dissId={diss_id}&srCodeNm={urllib.parse.quote(name)}"
    r = s.get(url, timeout=30); r.encoding = "utf-8"
    return r.text, url

def parse(html):
    soup = BeautifulSoup(html, "html.parser")
    date = ""
    m = re.search(r"감수일\s*([0-9.]+)", soup.get_text())
    if m: date = m.group(1)
    tabs, current_tab, current_sec = {}, None, None
    for el in soup.select("h3, h4, button, p, li, table"):
        t = el.get_text(" ", strip=True)
        if not t: continue
        if el.name == "h3" and t in ("개요","진단","치료","스스로 돕는 법"):
            current_tab = t; tabs[current_tab] = {}; current_sec = None
        elif current_tab and el.name in ("h4","button") and len(t) < 30:
            current_sec = t; tabs[current_tab].setdefault(current_sec, [])
        elif current_tab and current_sec:
            tabs[current_tab][current_sec].append(t)
    return date, tabs

def to_docx(idx, diss_id, name, date, tabs, url, out_dir):
    doc = Document()
    doc.add_heading(name, level=0)
    box = doc.add_paragraph()
    box.add_run(
        f"dissId: {diss_id}\n출처: {url}\n"
        f"발행기관: 보건복지부 국립정신건강센터, 대한신경정신의학회\n"
        f"감수일: {date}\n"
        f"라이선스: 공공누리 제4유형(출처표시·상업적이용금지·변경금지)\n"
        f"법적 한계 고지: 본 정보는 정신건강정보 이해를 돕는 참고자료이며, "
        f"개별 진단·치료는 의사 진료가 필요합니다."
    ).italic = True
    for tab in ("개요","진단","치료","스스로 돕는 법"):
        doc.add_heading(tab, level=1)
        sections = tabs.get(tab, {})
        if not sections:
            doc.add_paragraph("본 페이지에는 내용이 제공되지 않음."); continue
        for sec, lines in sections.items():
            doc.add_heading(sec, level=2)
            for ln in lines: doc.add_paragraph(ln)
    fname = f"{idx:02d}_{name.replace(' ','_').replace('/','_')}.docx"
    os.makedirs(out_dir, exist_ok=True)
    doc.save(os.path.join(out_dir, fname))
    return fname

def main():
    out = "./docs"; failed = []
    for i,(did,nm) in enumerate(DISEASES, start=1):
        try:
            html, url = fetch(did, nm)
            if "요청하신 페이지를 찾을 수 없습니다" in html or len(html) < 5000:
                raise RuntimeError("page-not-found-or-too-short")
            date, tabs = parse(html)
            f = to_docx(i, did, nm, date, tabs, url, out)
            print(f"OK {f}"); time.sleep(1.2)  # 정부 사이트 매너
        except Exception as e:
            failed.append((did, nm, str(e))); print(f"FAIL {did} {nm}: {e}")
    if failed:
        with open("failed.txt","w",encoding="utf-8") as fp:
            for did, nm, e in failed: fp.write(f"{did}\t{nm}\t{e}\n")

if __name__ == "__main__": main()
```

## Caveats
- **빈 탭/내용 누락 패턴**: 5개 검증 샘플에서 "우울과 우울장애"는 별도 역학 및 통계·DSM-5 전문이 없고 "조현병"은 자가검진 도구 표가 없는 등 탭별 누락은 질환마다 다르다. 스크래퍼는 누락 섹션을 "본 페이지에는 내용이 제공되지 않음"으로 자동 표기한다.
- **dissId 결번**: 인벤토리에서 dissId 1~7, 37, 39~53, 74+ 등은 사이트 목록에 등장하지 않는다. 임의 GET하면 404 또는 캐시 페이지가 반환되므로 사이트 목록의 50개만 신뢰하는 것이 안전하다.
- **세션 캐시 이슈**: 동일 세션에서 `srCodeNm` 없이 연속 GET하면 직전 캐시가 반환되는 현상이 다수 관찰됨. 스크래퍼는 매 질환마다 새 Session 객체 + 목록 페이지 prefetch로 우회한다.
- **이미지/다이어그램 손실**: 사이트 일부 표는 HTML 본문에 텍스트로 있지만 다이어그램·인포그래픽은 외부 이미지 서버(`/utl/web/imageSrc.do?path=...`)로 분리되어 있다. .docx에는 텍스트만 들어가며 이미지는 별도 옵션(`doc.add_picture` + 이미지 fetch)이 필요하다.
- **감수일 노후화**: 표본 5건이 모두 2020.05 감수로, DSM-5-TR(2022) 변경분(예: PMDD 정식 진단 격상, 지속성 비탄장애 추가)이 반영되어 있지 않다. RAG 응답에 감수일 메타데이터를 노출하기를 권장.
- **사이트 수치와 최신 문헌의 불일치**: 사이트가 인용한 일부 수치는 최신 메타분석과 차이가 있다(예: 조현병 5년 재발률 사이트 "90% 이상" vs Frontiers in Psychiatry 2021 "~81.9%"; BP-II 유병률 사이트 "유럽 3~6%" vs Merikangas 2011 WHO Survey "0.4%"). 챗봇 응답에는 사이트 인용을 1차 출처로 하되 최신 메타분석 보정 문구를 함께 노출하라.
- **라이선스 재확인**: 공공누리 제4유형은 "출처표시 + 상업적 이용 금지 + 변경 금지". 챗봇이 본문을 직접 인용·요약(변경)·상업적 서비스로 노출하는 행위는 모두 잠재적 위반이며 발행기관 공식 라이선스 페이지(kogl.or.kr)에서 재확인 필수.
- **실제 .docx 미생성**: 본 보고서는 텍스트뿐이며 50개 바이너리 .docx를 생성하지 못한다. 위 스크래퍼 실행이 곧 산출물 발행에 해당한다.
