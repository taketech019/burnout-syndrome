## 1. 개요 — CounsHelper (가칭)

사설 상담센터 심리상담사를 위한 AI 기반 상담 기록·분석·보고서 자동화 플랫폼.

상담사가 50분 회기 후 보고서 작성·다음 회기 계획·진행 추이 정리에 쓰는 시간을 AI가 줄여, 핵심 상담에 집중할 수 있게 한다.

### 단계별 진화

| 단계 | 처리 | 핵심 추가 |
| --- | --- | --- |
| MVP (~5/29) | **하이브리드** (챗봇 로컬, 라벨링·요약 외부), 데모 데이터 한정 | 공공 AI 모델, 로컬 sLLM RAG 챗봇 |
| 상용 v1 (~2026 하반기) | 하이브리드 강화 | 자동 익명화, 다중 사용자, 결제 |
| 상용 v2 (~2027) | 완전 로컬 (라벨링·요약도 로컬) | 음성 STT |

### 시장 위치

레퍼런스: **위노트AI** (학교 전문상담교사, 완전 로컬). 우리는 **사설 상담센터** — 미진출 시장.

**차별점 4가지**: ① AI Hub 공공 AI 모델(KlueBERT 판별 + Koalpaca 요약) + **로컬 sLLM(Qwen2.5)** RAG 챗봇으로 민감 데이터 보호 ② 증상·위험·개선·개입 4범주 정량 분석 ③ HIRA 인구통계 컨텍스트 ④ 유사 케이스 RAG.

## 2. 타겟: 상담센터 심리상담사

사설 상담센터 상담심리사 1급, 5년차, 주 15회기. 회기 50분 + 보고서 30분(실질 80분 노동), 회기 간 기억 흐림, 장기 추이 정리 어려움, 인구통계 맥락 부족, 유사 케이스 참조 어려움. 지불 의향 월 3~5만원.

**전제**: 이미 상담 중인 내담자의 회기를 *분석*하는 보조 도구. 진단 도구가 아님 (진단은 의료 영역).

**비대상**: 학교 상담교사(위노트AI), 정신과 의사, B2C, 우울·불안·중독 외 정신질환.

## 3. MVP 범위

| ID | 기능 |
| --- | --- |
| F1 | 상담 텍스트 → 우울·불안·중독 판별 + 4범주 요인 분석 |
| F2 | 내담자 맞춤 대시보드 |
| F3 | 요약 보고서 (.md/.pdf/.docx, 차트 포함) |
| F4 | RAG 챗봇 |
| F5 | 내담자/회기 관리 |

## 4. 기능 명세

### F1. 판별 + 4범주 요인 분석

- 입력: 상담 텍스트(발화자 구분 스크립트), 내담자 메타(성별·연령·지역, 익명 ID)
- 데모 데이터 한정 가드레일 (입력 화면 경고, placeholder 예시)
- **AI Hub KlueBERT** → 우울/불안/중독 판별 (정상군 포함 분류)
- 정상군·범위 외 판정 시 안내 후 중단
- 양성 시 **Gemma 4 31B few-shot**으로 발화 단위 0/1 라벨링:
  - **증상요인**: 판별된 질환의 하위세트 (우울 10 / 불안 8 / 중독 10 중 택1)
  - **위험요인 20 / 개선요인 5 / 개입요인 11** (공통)
- 발화 단위 0/1 라벨을 **회기 단위 빈도로 집계** (요인별 등장 횟수·비율)
- 출력: JSON (회기 메타 + 발화별 라벨 + 회기 빈도 집계)
- 기준: 발화 단위 분류 F1 ≥ 0.70 (AI Hub 평가셋), 처리 ≤ 90초

### F2. 내담자 맞춤 대시보드

- **회기 문제 수준 카드**: KlueBERT 판별 결과 + depression/anxiety/addiction 정도값 (예: 중=2)
- **4범주 빈도 차트**: 증상·위험·개선·개입 요인별 회기 내 등장 빈도 가로 막대
- **회기별 추이 라인**: 핵심 요인 3~5개의 빈도 변화
- **HIRA 인구통계 비교**: 예 *"30대 여성 서울 우울증 진료율 8.3%, 전국 6.1%"*
- 기준: 페이지 로드 ≤ 3초

### F3. 요약 보고서

- **AI Hub Koalpaca 요약 모델 직접 사용** (Apache 2.0)
- 4섹션 생성: 주요 증상 / 위험 요인 / 개선 요인 / 상담사 개입 요인 (데이터 `summary` 구조와 동일)
- 다음 회기 계획 추천 (목표·기법·과제)
- 텍스트 편집 가능
- 출력 포맷 3종, 모두 대시보드 차트 이미지 포함:
    - **.md** (복사·노션), **.pdf** (인쇄), **.docx** (편집)
- 기준: AI Hub 공식 F-1 60.94% 인용, 다운로드 ≤ 10초

### F4. RAG 챗봇

- 사이드바 UI (위노트AI 스타일)
- **로컬 sLLM**: Ollama + **Qwen2.5 7B** (외부 API 미사용, 민감 텍스트 외부 전송 없음)
- **임베딩**: KoSBERT (`snunlp/KR-SBERT-V40K-klueNLI-augSTS`) — 한국어 특화
- **벡터 DB**: ChromaDB (로컬 파일)
- **프레임워크**: LangChain (`RetrievalQA`, `k=5` 상위 5개 검색)
- 검색 소스: AI Hub 학습 데이터 465K건 + 임상 가이드라인 PDF
- 모든 응답에 출처 표시
- **고지**: *"본 시스템은 상담사의 임상적 판단을 대체하지 않으며, 상담 기록 정리와 회기 계획 수립을 보조하는 참고용 도구입니다."*
- 기준: P95 ≤ 5초, 출처 정확도 ≥ 0.80

### F5. 내담자/회기 관리

내담자·회기 목록(날짜순·검색), 신규 등록, JSON 내보내기.

## 5. 데이터

### AI Hub 심리상담 데이터 (데이터셋 71806)

**라벨 구조** — 4개 카테고리, 총 64개 라벨:

| 카테고리 | 개수 | 비고 |
| --- | --- | --- |
| symptom_factor 증상요인 | 28 | 우울 10 / 불안 8 / 중독 10 — 질환별 분리 |
| risk_factor 위험요인 | 20 | 공통 (질환별 하위세트는 설명서 확인) |
| symptom_change 개선요인 | 5 | 공통 |
| intervention_factor 개입요인 | 11 | 공통 |

- 라벨 값: 발화(paragraph) 단위 0/1
- 회기 메타: `depression`/`anxiety`/`addiction` 문제 수준 정도값, `class` 4분류

**활용 자원**

| 자원 | 사용처 | 비고 |
| --- | --- | --- |
| 라벨링 JSON 465K건 (상담 1,661건) | RAG 인덱싱, 발화 단위 평가셋, 향후 미세조정 | 다운로드 완료 |
| KlueBERT 판별 모델 | F1 판별 | Apache 2.0 ✅ |
| Koalpaca 요약 모델 | F3 요약 | Apache 2.0 ✅ |

### HIRA (opendata.hira.or.kr)

- 정신질환 진료 통계 (연령·성별·지역) → F2
- 정신과 의약품 처방 통계 → F4
- 정확한 데이터셋 픽은 차기 회의

## 6. AI 아키텍처

```
입력 (상담 텍스트 + 메타)
  ↓
[① 판별] KlueBERT → 우울/불안/중독/정상
  ├─ [정상·범위 외] → 안내 후 종료
  └─ [양성]
       ├─ [② 발화 단위 라벨링] Gemma 4 31B (API)
       │     증상요인(질환별 10/8/10) + 위험20 + 개선5 + 개입11 → 0/1
       │     → 회기 단위 빈도 집계
       ├─ [③ 요약]  Koalpaca → 4섹션
       └─ [④ RAG]   Qwen2.5 7B (Ollama 로컬) + KoSBERT + ChromaDB + LangChain
  ↓
[⑤ HIRA 통계 매칭]
  ↓
출력: 보고서(.md/.pdf/.docx + 차트) / 대시보드 / 챗봇
```

## 7. 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어·UI | Python 3.11, Streamlit |
| 판별·요약 모델 | transformers, torch (KlueBERT, Koalpaca) |
| 발화 라벨링 LLM | Gemma 4 31B (`gemma-4-31b-it`) — Google AI Studio API 경유 |
| **RAG 챗봇 LLM** | **Ollama + Qwen2.5 7B (로컬)** |
| 임베딩 | **KoSBERT** (`snunlp/KR-SBERT-V40K-klueNLI-augSTS`) |
| RAG 프레임워크 | **LangChain**, ChromaDB |
| 시각화 | plotly, kaleido (차트 이미지화) |
| 보고서 출력 | python-docx, weasyprint, markdown |
| 환경변수 | python-dotenv |

## 8. 비기능

- **개인정보**: MVP는 데모 데이터 전용 (가드레일 UI), 자동 익명화는 Phase 1
- **보안**: API 키 `.env`, HTTPS (Streamlit Cloud), 단일 데모 계정
- **성능**: 텍스트 분석 ≤ 90초, 챗봇 P95 ≤ 5초, 대시보드 ≤ 3초, 보고서 다운로드 ≤ 10초
- **사용성**: 한국어, 데스크탑 우선 (1280px+)
