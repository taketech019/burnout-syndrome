## 1. 개요

사설 상담센터 심리상담사를 위한 AI 기반 상담 기록·분석·보고서 자동화 플랫폼.

상담사가 50분 회기 후 보고서 작성·다음 회기 계획·진행 추이 정리에 쓰는 시간을 AI가 줄여, 핵심 상담에 집중할 수 있게 한다.

### 단계별 진화

| 단계 | 처리 | 핵심 추가 |
| --- | --- | --- |
| MVP (~5/29) | 클라우드, 데모 데이터 한정 | 공공 AI 모델, RAG 챗봇 |
| 상용 v1 (~2026 하반기) | 하이브리드 | 자동 익명화, 다중 사용자, 결제 |
| 상용 v2 (~2027) | 완전 로컬 | 음성 STT |

### 시장 위치

레퍼런스: **위노트AI** (학교 전문상담교사, 완전 로컬). 우리는 **사설 상담센터** — 미진출 시장.

**차별점 4가지**: ① AI Hub 공공 AI 모델 직접 활용(KlueBERT 판별 + Koalpaca 요약) ② 28개 증상 요인 정량 추출 ③ HIRA 인구통계 컨텍스트 ④ 유사 케이스 RAG.

## 2. 타겟: 상담센터 심리상담가

사설 상담센터 상담심리사 1급, 5년차, 주 15회기. 회기 50분 + 보고서 30분(실질 80분 노동), 회기 간 기억 흐림, 장기 추이 정리 어려움, 인구통계 맥락 부족, 유사 케이스 참조 어려움. 지불 의향 월 3~5만원.

**비대상**: 학교 상담교사(위노트AI), 정신과 의사, B2C, 우울·불안·중독 외 정신질환.

## 3. MVP 범위

| ID | 기능 |
| --- | --- |
| F1 | 상담 텍스트 → 우울·불안·중독 판별 + 28요인 추출 |
| F2 | 내담자 맞춤 대시보드 |
| F3 | 4섹션 요약 보고서 (.md/.pdf/.docx, 차트 포함) |
| F4 | RAG 챗봇 |
| F5 | 내담자/회기 관리 |

## 4. 기능 명세

### F1. 판별 + 28요인 분석

- 입력: 상담 텍스트, 내담자 메타(성별·연령대·지역, 익명 ID)
- 데모 데이터 한정 가드레일 (입력 화면 경고, placeholder 예시)
- **AI Hub KlueBERT** → 우울/불안/중독 각 0/1
- 일반군·범위 외 질환 의심 시 안내 후 중단
- 양성 시 **Gemini few-shot**으로 28요인 0~3 점수
- 출력: JSON (`depression`, `anxiety`, `addiction`, `symptom_factor` 등)
- 기준: Gemini 28요인 F1 ≥ 0.70, 처리 ≤ 90초

### F2. 내담자 맞춤 대시보드 (차트 추가 및 데이터 수집 필요)

- **카테고리 평균 카드**: 우울/불안/중독 평균 점수
- **세부 요인 가로 막대**: 28요인을 카테고리별 그루핑
- **회기별 추이 라인**: 핵심 요인 3~5개
- **HIRA 인구통계 비교**: 예 *"30대 여성 서울 우울증 진료율 8.3%, 전국 6.1%"*
- **위험도 게이지**: KlueBERT 출력 시각화
- 기준: 페이지 로드 ≤ 3초

### F3. 요약 보고서

- **AI Hub Koalpaca 요약 모델 직접 사용** (Apache 2.0)
- 4섹션 생성: 주요 증상 / 위험 요인 / 개선 요인 / 상담사 개입 요인
- 다음 회기 계획 추천 (목표·기법·과제)
- 텍스트 편집 가능
- 출력 포맷 3종, 모두 대시보드 차트 이미지 포함:
    - **.md** (복사·노션), **.pdf** (인쇄), **.docx** (편집)
- 기준: AI Hub 공식 F-1 60.94% 인용, 다운로드 ≤ 10초

### F4. RAG 챗봇

- 사이드바 UI (위노트AI 스타일)
- 유사 케이스 검색 (AI Hub 학습 데이터 465K건)
- 임상 가이드라인 검색 (PDF)
- 이론 Q&A
- 모든 응답에 출처 표시
- 기준: P95 ≤ 5초, 출처 정확도 ≥ 0.80

### F5. 내담자/회기 관리

내담자·회기 목록(날짜순·검색), 신규 등록, JSON 내보내기.

## 6. AI 아키텍처

```
입력 (상담 텍스트 + 메타)
  ↓
[① 판별] KlueBERT → 우울/불안/중독 0/1
  ├─ [일반군·범위 외] → 안내 후 종료
  └─ [양성]
       ├─ [② 28요인] Gemini few-shot
       ├─ [③ 요약]   Koalpaca → 4섹션
       └─ [④ RAG]    ChromaDB + bge-m3
  ↓
[⑤ HIRA 통계 매칭]
  ↓
출력: 보고서(.md/.pdf/.docx + 차트) / 대시보드 / 챗봇
```

## 7. 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어·UI | Python 3.11, Streamlit |
| 판별·요약 | transformers, torch (KlueBERT, Koalpaca) |
| 28요인·챗봇 LLM | Gemini API (gemma-4-26b-it) |
| RAG | LangChain, ChromaDB, sentence-transformers (bge-m3) |
| 시각화 | plotly, kaleido (차트 이미지화) |
| 보고서 출력 | python-docx, weasyprint, markdown |
| 환경변수 | python-dotenv |

## 8. 비기능

- **개인정보**: MVP는 데모 데이터 전용 (가드레일 UI), 자동 익명화는 Phase 1
- **보안**: API 키 `.env`, HTTPS (Streamlit Cloud), 단일 데모 계정
- **성능**: 텍스트 분석 ≤ 90초, 챗봇 P95 ≤ 5초, 대시보드 ≤ 3초, 보고서 다운로드 ≤ 10초
- **사용성**: 한국어, 데스크탑 우선 (1280px+)
